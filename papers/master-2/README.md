# Self-dual forms with a pole and the smooth four-dimensional Poincaré conjecture

The second master asks one question. Does every smooth homotopy four-sphere $M$ carry a conformal class $c$ and a point $p$ for which some pole form, a closed $c$-self-dual two-form on $M\setminus p$ with a pole of order four at $p$, has no zeros? With two independently replayed project theorems, existence of the pole forms on every class and recognition of $S^4$ from a zero-free one, an affirmative answer is equivalent to smooth Poincaré. The equivalence is a reformulation of the conjecture. The question is open.
