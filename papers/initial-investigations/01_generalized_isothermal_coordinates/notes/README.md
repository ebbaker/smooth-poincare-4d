# Research notes

Preserve inherited obstruction analysis as a dated scientific note. New research belongs in new dated files, with any supersession stated explicitly.

Each new note identifies its question, assumptions, conventions, date, author/assistance, actual recorded model and effort if available, derivation, evidence, limitations, and consequence for the current task. Distinguish source results from proposed extensions. Link the [sole live register](../research-progress/REGISTER.md); do not maintain a second task ledger here.
