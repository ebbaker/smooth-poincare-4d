## Boundary weights and the two products

For a connected compact manifold $M$, the isomorphism classes of principal $G$-bundles are $H^1(M;\mathbb F_2)$. Each class has automorphism group $G$, since $G$ is abelian and a bundle automorphism is a locally constant $G$-valued function. Thus a connected boundary component has weight $1/2$ per class. Use smooth oriented bordisms with the prescribed boundary identifications. For a connected $W$ with $r\ge1$ connected boundary components, fix one representative bundle on each boundary component. Every extending class over $W$ admits $2^r$ ways to identify its restrictions with those representatives, since each such identification set is a $G$-torsor. Taking the free diagonal quotient by the two constant automorphisms gives $2^{r-1}$ relative classes per extending class. A relative class has trivial automorphism group. The kernel $K_W$ is the weighted count with these fixed boundary bundles and identifications. Applying that kernel integrates each incoming connected boundary variable with weight $1/2$. For example, the cylinder on a connected boundary has kernel $2\delta_{a,b}$, giving the identity after one boundary sum. **Local-operator algebra.** Write $P_n$ for $D^n$ with two disjoint open interior $n$-balls removed. Reutter's $m_3$ is $P_4:S^3\sqcup S^3\to S^3$, and $u_3$ is $D^4:\varnothing\to S^3$. The three spheres all have unique boundary class. The punctured ball $P_4$ is simply connected, as follows by gluing the interior balls back along simply connected spheres and applying van Kampen. There is one extending class, so $K_{P_4}(0;0,0)=4$. The two incoming weights multiply to $1/4$, giving $m(a,b)=ab$ on $Z(S^3)=\mathbb C$ in the basis given by the function $1$. The disk has one component on its boundary, one extension, and relative weight $1$, so the unit is $1$. **Fusion algebra.** Reutter's $m_2\times S^1$ is $P_3\times S^1$ with the identified $S^2\times S^1$ boundaries, and $u_2\times S^1$ is $D^3\times S^1$. Reversing the circle generator would give the same restriction in $\mathbb F_2$. For outgoing class $h$ and incoming classes $a,b$, the kernel is $4\delta_{h,a}\delta_{h,b}$. Hence

$$
m(f,g)(h)=\sum_{a,b\in\mathbb F_2}\frac14\,4\delta_{h,a}\delta_{h,b} f(a)g(b)=f(h)g(h).
$$

Thus $Z(S^2\times S^1)=\mathbb C\times\mathbb C$, with orthogonal idempotents $\delta_0$ and $\delta_1$. Both this algebra and the local-operator algebra $\mathbb C$ are semisimple. This verifies Reutter's two algebra hypotheses for the ordinary oriented finite-gauge functor.
