# Field theory for smooth-sphere comparisons

Can a field-theoretic observable distinguish a smooth homotopy four-sphere
at lower cost than the geometric counterexample test? The starting
experiment uses the gauge and spinor fields on a tube around a twisted
zero-circle in a standard model, then asks whether any relative data
survive changing the frame and gluing back the tube. The investigation
also compares spacetime twists, low-energy twistor constructions and a
possible off-shell field theory on nonround metrics.
