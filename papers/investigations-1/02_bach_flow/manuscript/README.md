# Working manuscript

[Bach flow and the smooth four-dimensional Poincaré conjecture](bach_flow_and_smooth_poincare.tex), Edward B. Baker III. The draft derives the smooth-interval Yamabe estimate and applies the marked-volume theorem to almost critical late slices. It uses the [shared bibliography](../../../../references/references.bib).

From the repository root, run `python3 tools/build_manuscripts.py 02_bach_flow`. The reading copy goes in `output/pdf/02_bach_flow/`. See the [draft history](../DRAFT_HISTORY.md) for the inherited opening.
