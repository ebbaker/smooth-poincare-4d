Define the set of chiral critical values of smooth positive-Yamabe Bach-flat metrics on all smooth homotopy four-spheres having $0<E<8\pi^2$. This varies the underlying smooth structure because the capped side of an embedded sphere could differ smoothly from the source. No existence is assumed. If the set is nonempty, a sequence tending to its infimum is uniformly subcritical. A nonflat smooth leaf in an exact Bach-flat compactness alternative would yield a new smooth closed critical value strictly lower than the infimum, by the strict residual estimate. If that compactness alternative is justified, the infimum is attained; Chang–Chen then gives a strict interval above $4\pi^2$ free of critical values. This optimization is over critical points, not over all metrics, so it supplies neither a minimizer of the unrestricted Weyl functional nor a stability assertion.
