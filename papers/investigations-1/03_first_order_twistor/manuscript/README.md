# Working manuscript

[First-order twistor integrability and the smooth four-dimensional Poincaré conjecture](first_order_twistor_and_smooth_poincare.tex),
Edward B. Baker III. The draft shares the Bach manuscript's opening and
then develops the local section criterion, the spinor and chiral
connection formulations, the three-axis defect estimate and marked energy accounting on an actual smooth source. The final section identifies the open separating-cut and closed-base problems.

Build the reading copy from the repository root with
`python3 tools/build_manuscripts.py 03_first_order_twistor`. The generated
PDF goes in `output/pdf/03_first_order_twistor/`. See the
[draft history](../DRAFT_HISTORY.md) for the exact inherited span and the
[reference guide](../references/README.md) for the shared bibliography.
