This parent investigation asks whether first-order geometric or spinorial
equations can construct a smooth Riemannian conformal class with W⁺ = 0
on every smooth homotopy four-sphere. Such a construction would imply
the smooth Poincaré conjecture. The recognizing implications are known;
global construction remains the open step.
