# Assessments and audits

Keep hypothesis audits, proof checks, normalization checks, and manuscript assessments here. An inherited audit retains its original status. New assessments name exact sources and separate verified steps, unverified premises, and proposed corrections. State whether a review is independent; do not infer independence from a model change.

The first declared audit is specified in [PLAN.md](../research-plan/PLAN.md); [REGISTER.md](../research-progress/REGISTER.md) owns its live status.
