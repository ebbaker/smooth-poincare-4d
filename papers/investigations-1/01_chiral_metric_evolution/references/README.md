# Branch reference guide

The shared reference collection is [../../../../references/](../../../../references/README.md), including Edward B. Baker III’s original unfinished drafts. Refer to the shared copy rather than creating duplicate PDFs here. Branch-specific reading notes and precise citation records may be added when needed.

Follow [REFERENCE_WORKFLOW.md](../../../../REFERENCE_WORKFLOW.md). Distinguish author drafts from published sources and check a cited theorem’s actual hypotheses before relying on it. Bibliographic presence does not imply that a result has been independently verified for this investigation.

The [21 November background source notes](../../../../references/SOURCE_NOTES_CME_BACKGROUND_20261121.md) record passages checked for the revised introduction and Section 2. In this manuscript, the author's work is cited only as [arXiv:2301.00029](https://arxiv.org/abs/2301.00029) and references within. Earlier repository manuscripts informed the exposition but are not cited; their preservation in the shared collection does not change that citation policy.
