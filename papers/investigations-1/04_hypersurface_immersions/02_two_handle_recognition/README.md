# Recognizing smooth types from two-middle-handle heights

[Working paper (PDF)](../../../../output/pdf/04_hypersurface_immersions/02_two_handle_recognition/recognition_from_marked_morse_heights.pdf) · [Editable manuscript and build](manuscript/README.md)

25 November 2026 (UTC). Prepared for Edward B. Baker III with OpenAI Codex assistance. Actual serving model and reasoning effort unavailable. [Input versions](research-overview/OVERVIEW.md#input-versions)

Can geometric information from a Morse height of a Euclidean hypersurface immersion simplify its marked two-middle-handle presentation enough to recognize the standard smooth four-sphere?

Start with the mixed reduced \((m_1,m_3)=(1,1)\) case. Seek a framed attaching circle that meets the actual belt sphere of the 1-handle transversely once, possibly after a justified handle slide. The one-sided case \((0,2)\) and its dual \((2,0)\) require extra geometric information about a two-component surgery diagram.
