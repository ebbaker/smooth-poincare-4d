## Existence when the marked class is allowed to vary

Sweeney's Proposition 1.2 applies to the actual (W) because it is contractible and its handle presentation uses one handle of index (0,1,2) each, the definition in footnote 4. The proposition gives a smooth positive-scalar-curvature metric with mean-convex boundary, controlling neither its boundary conformal class nor the Weyl energy. The singleton case of Bär–Hanke Theorem 3.7 with (sigma=0) and target tensor (k=0) applies since the trace of the target is at most the original mean curvature. The induced boundary metric is fixed by part (c) and the terminal second fundamental form vanishes by part (d). In the normal collar from Definition 3.1 the terminal tensor is ((1-Ct^2)gamma_0), so even extension gives a smooth reflection-invariant PSC metric on the actual identity double. In particular the marked boundary metric (gamma_0) lies in an open set of filled boundary metrics. Adding a small (C^2) tangential perturbation with a cutoff constant near the face keeps the normal part and its vanishing tangential derivative, so the assertion is about the actual smooth half and marking. [Sweeney, Proposition 1.2 and footnote 4](https://arxiv.org/pdf/2507.15719#page=3) · [Bär–Hanke v5, Definition 3.1 and Theorem 3.7](https://arxiv.org/pdf/2012.09127#page=19)

Shi–Wang–Wei gives PSC with the exact prescribed boundary first fundamental form. Its proof uses a product-topological boundary collar and a conformal smoothing keeping the outer boundary metric fixed. A smooth collar reparametrization identifies the enlarged half with the original half and restricts to the original marking on the outer boundary. Neither Theorem 1.1 nor its Remark 2.1 ensures that the allowed outward mean curvatures include zero. [Shi–Wang–Wei v3, Theorem 1.1, proof and Remark 2.1](https://arxiv.org/pdf/2007.06756#page=11)

For each extension class one can first normalize boundary mean curvature to zero.
