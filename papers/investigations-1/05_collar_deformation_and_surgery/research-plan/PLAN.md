## Scope of a successful return

After reducing end trees to one minimum and one maximum, $n_1+n_3=n_2$. The recognized base cases have $n_2\le1$. For a hypothesized least-count nonstandard presentation, a same-type move with net strict decrease contradicts minimality. Results that cover a specified mixed or one-sided class apply on that class. An induction across a wider class would require a proved selection lemma for every remaining member, actual return to an allowed successor, and valid base cases. Such universal selection is an open global premise, as is recognition across the unrestricted one-sided two-middle-handle class. The [marked height results](../../04_hypersurface_immersions/02_two_handle_recognition/manuscript/recognition_from_marked_morse_heights.tex) give the inherited cases. Low-energy immersed height selection has its own immersion hypothesis and calls for recognition of an actual marked height. [Immersed height theorem](../../../master/manuscript/immersion_entry.tex)
