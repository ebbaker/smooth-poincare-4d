# Bour's flow and fixed-type attainment

Suppose a closed oriented smooth homotopy four-sphere \(M\) has a positive Yamabe class with chiral Weyl energy below \(8\pi^2\). Does \(M\) itself carry a smooth positive Bach-flat class attaining the infimum \(I^+(M)\)? Bour's fourth-order flow provides a dichotomy for each fixed regularization parameter. The problem here is to follow both outcomes back to the original smooth type as the parameter tends to zero.
