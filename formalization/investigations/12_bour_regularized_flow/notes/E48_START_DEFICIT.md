## Equivalent geometric start conditions

For a fixed $\delta>0$, define the restricted set

$$
A_\delta=\{E_+(g):Y([g])>0,\;
    384\pi^2-Y([g])^2\ge\delta\}.
$$

Membership includes the same actual integrability witness as the unrestricted set. Then $A_\delta\subset A$, where $A$ is the full positive-class energy set, and every element of $A_\delta$ is at least $I=\inf A$. The condition $A_\delta\ne\varnothing$ and $\inf A_\delta=I$ is equivalent to each interval $[I,I+\varepsilon)$, $\varepsilon>0$, meeting $A_\delta$. Nonemptiness is necessary in the real Lean infimum API. The equivalence is a criterion for approximate attainment. Assume the entered bound $I<2T$ and the E47 normalization input. Set $\eta=(2T-I)/2$ before choosing the parameter schedule. For each prescribed $\alpha_j>0$, use the restricted set at tolerance $\min(\alpha_j^2,\eta)$. Normalization preserves $e$ and $Y$. The resulting actual metric has unit volume, constant scalar $Y>0$, $\int R^2\,dV=Y^2$, $e\le 2T-\eta$, $0\le e-I\le\alpha_j^2$, and $b\ge\delta$. Conversely, recovery on any one eventual tail with $\alpha_j\to0$ puts an element of $A_\delta$ into every such interval. ## Pointed consequences in the original gauge

On a marked positive first pointed return, E47 gives $b(g_{j,0})\le48\alpha_j$ from the ordinary Ricci comparison, the Euclidean-end identity $D_X=4e_X$ and admissibility of the actual same-type compactification. A fixed $\delta>0$ excludes such a return at every sufficiently late index. On the extracted second sequence the E47 contract uses the closed or marked first return at each index, physical energy and Ricci lower semicontinuity on the second extraction, and the positive same-type marked return. It forces $Y([g_{j,0}])^2\to384\pi^2$ on those very starts. The upper bound $Y([g_{j,0}])^2\le384\pi^2-\delta$ survives restriction to any cofinal subsequence and contradicts that limit. These arguments apply when the corresponding comparison and marking data are supplied. ## Scope of the missing estimate

Strict Yamabe comparison supplies $b(g)>0$ for each positive class outside the conformally round sphere. Its quantifier is an individual class. Even a sequence with strict comparison at every index can have its deficits tending to zero. At the scalar level $b_j=1/(j+1)$ illustrates the quantifier difference. This is a scalar example illustrating the quantifiers. The precise missing geometric statement is one $\delta>0$ for which $A_\delta$ recovers $I$. If every such restricted set fails to recover $I$, every positive minimizing sequence satisfying the round bound saturates it. Indeed, for each $\delta>0$ the failed restricted set omits some entire energy interval $[I,I+\varepsilon)$, so a late minimizing tail has deficit strictly below $\delta$. [Schoen, Theorem 2 and §3](https://math.jhu.edu/~js/Math646/schoen.yamabe.pdf#page=15) · [Failure forces saturation](../../../SmoothPoincare/Variational/BourStartDeficit.lean)

An already attained positive class with $Y<Y(S^4)$ gives the restricted condition by a constant normalized sequence at energy $I$. Its fixed deficit is $Y(S^4)^2-Y^2>0$. This recovery depends on attainment and therefore follows the compactness step it would otherwise simplify. The named round class has zero deficit.
