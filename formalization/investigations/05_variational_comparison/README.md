# 05 · Fixed-type variational comparison

Given positive metrics approaching the chiral Weyl infimum on one smooth homotopy four-sphere, which local changes can lower their energy? This investigation starts with independently marked repairs. It then follows same-type replacement to strong convergence on fixed compact domains and studies where the remaining physical energy can lie. Route 03 constructs and closes the marked cuts.
