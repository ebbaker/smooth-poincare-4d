# 05 · Fixed-type variational comparison

Given positive metrics approaching the chiral Weyl infimum on one smooth homotopy four-sphere, compare each locally repaired metric with every admissible metric on that smooth type. This route develops individual replacement, the positive path and strong chiral convergence on marked compacts. Route 03 uses these ingredients for a single marked cut.
