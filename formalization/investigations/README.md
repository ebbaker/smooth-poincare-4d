# Formalization investigations

Use the [formalization setup workflow](../FORMALIZATION_SETUP_WORKFLOW.md)
to plan and track families of Lean proofs. The [shared blueprint](../blueprint/README.md)
records mathematical dependencies across these investigations.

## Overall research program

Version 01 follows the first-order twistor, Sections and Connections, and Dirac manuscripts up to the collar and neck problems. It gives separate conditional targets for full energy accounting, a single spherical cut, and spinor matching on supplied geometry.
