[IMPORT_MANIFEST.json](IMPORT_MANIFEST.json) maps all 36 substantive files from their source-relative paths to destination-relative paths, records source/destination SHA-256 hashes, and identifies every link-only modification. LaTeX, Python and PDF sources are byte-preserved. Markdown scientific text is unchanged; stale absolute paths and one already-broken companion link were repaired. Original inputs remain in place.

Temporary render images, TeX build products, duplicate temporary PDFs, OS metadata, and empty original folders were not imported. The original empty chat-histories folder is replaced by explicit workflow guidance. Unrelated research and archives from the workflow-template repository are not part of this import.

The source snapshot and import hashes identify imported bytes; they are not mathematical certificates. Subsequent edits may legitimately differ and must be documented in the branch's history.

The [21 November access and completeness audit](reviews/REPOSITORY_AUDIT_20261121.md)
verified the current hyphenated repository location, all 36 source/destination
hashes and the applied layout. Original intended paths in the import manifest
remain historical provenance.
